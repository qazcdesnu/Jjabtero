# Jjabtero

데이터사이언스 대학원생 한 명을 위한 개인 서지관리 앱이다. Zotero를 대체하는 것을 목표로, 내 컴퓨터에서 로컬 웹 앱으로 실행한다. 논문 검색과 필터, 읽기 상태와 메모 관리, 인용 관계로 논문을 연결하고 추천하는 기능, 서재 통계와 시각화 기능을 만든다.

아직 개발 초기 단계라서 앱 기능은 없고 패키지 골격만 있다.

## 설치와 실행

Python 3.14와 [uv](https://docs.astral.sh/uv/)를 쓴다. uv가 없으면 먼저 설치한다. Python 3.14는 uv가 필요할 때 자동으로 받는다.

```sh
uv sync          # 가상 환경을 만들고 의존성을 설치한다
uv run pytest    # 테스트를 실행한다
```

앱 실행 방법은 웹 화면을 만든 뒤 여기에 적는다.
