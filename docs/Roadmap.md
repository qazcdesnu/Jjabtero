# 로드맵

이 문서는 할 일을 마일스톤(M)과 태스크(T)로 나눈 목록이다. 각 태스크는 한 줄로 무엇을 할지만 적는다. ID와 상태 표기, 작업 흐름은 [작업 관리 규칙](TaskRule.md)을 따르고, 진행 중인 작업의 상세는 [진행 중](Ongoing.md)에, 끝난 작업의 상세는 [완료](Done.md)에 있다. 전체 문서 목록은 [문서 인덱스](index.md)에서 확인한다.
