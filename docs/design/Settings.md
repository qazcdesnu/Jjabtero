# 사용자 설정 설계

이 문서는 사용자가 앱 안에서 바꾸는 설정을 정한다. 처음 생기는 설정은 인용 데이터를 가져오는 양이다([인용 데이터 설계](Citations.md#3-가져오는-범위)). 비밀 값과 배포 환경 값은 설정이 아니라 환경 변수로 둔다([배포 설계](Deployment.md#3-데이터와-비밀-값)). 전체 문서 목록은 [문서 인덱스](../index.md)에서 확인한다.

## 1. 항목

| 키 | 뜻 | 기본값 | 허용 범위 |
| --- | --- | --- | --- |
| `citing_limit` | 서재 논문마다 가져올 최근 1년 피인용의 최대 건수(최신 순) | 200 | 1~1000의 정수 |

- 사용자가 정한 것만 설정으로 둔다. 피인용 기간 1년은 설정이 아니다. 사용자가 최대 건수만 조절하면 된다고 정했다.
- 항목을 더할 때는 이 표에 키, 뜻, 기본값, 허용 범위를 적는다.

## 2. 저장

- 설정은 서재 파일(`library.db`)의 `settings` 표(키, 값)에 둔다. 서재와 함께 드라이브로 동기화되어, 로컬과 서버 어디서 바꿔도 같은 값을 쓰기 위해서다. 표는 마이그레이션 0003이 만든다.
- 표에 없는 키는 기본값을 쓴다. 기본값을 바꿔도 사용자가 고친 적 없는 설정은 새 기본값을 따르게 하기 위해서다.

## 3. API와 화면

- `GET /api/settings`는 모든 항목의 현재 값을, `PUT /api/settings`는 바꿀 항목만 받아 검사한 뒤 저장한다. 허용 범위를 벗어나거나 모르는 키면 422로 거절한다.
- 화면 머리줄에 설정 버튼을 두고, 누르면 설정 창을 연다. 항목마다 이름, 설명, 입력 칸을 두고 저장 버튼으로 저장한다.
- 세부 구현은 M3-T3에서 정한다.
