# 공개 페이지 설계

이 문서는 로그인 없이 열리는 두 페이지, 앱 소개(`/about`)와 개인정보처리방침(`/privacy`)을 정한다. 두 페이지는 구글 OAuth 동의 화면을 프로덕션으로 게시하는 데 필요하다([배포 설계](Deployment.md#4-oauth-동의-화면-게시)). 무엇을 공개하는지는 [배포 설계의 공개 범위](Deployment.md#2-공개-범위)에 있다. 전체 문서 목록은 [문서 인덱스](../index.md)에서 확인한다.

## 1. 제공 방식

- 두 페이지는 [public_pages 모듈](../../src/jjabtero/public_pages.py)의 [router](../../src/jjabtero/public_pages.py#router)가 서버에서 완성된 HTML로 돌려준다. 프론트엔드 앱(Vue)을 거치지 않는다. 구글 심사자나 크롤러가 자바스크립트 없이도 내용을 읽을 수 있어야 하고, 앱 화면은 로그인 상태부터 묻기 때문이다.
- `GET /about`은 [about](../../src/jjabtero/public_pages.py#about)이, `GET /privacy`는 [privacy](../../src/jjabtero/public_pages.py#privacy)가 처리한다.
- `/api` 밖의 경로라 [로그인 미들웨어](Auth.md#4-막는-범위)가 막지 않는다. 로그인이 켜져 있어도 로그인 없이 열린다.
- [create_app](../../src/jjabtero/app.py#create_app)은 이 라우터를 정적 파일 마운트보다 먼저 등록한다. 정적 파일이 `/` 전체를 차지하기 때문이다.
- 페이지에는 외부 스크립트, 글꼴, 추적 코드를 넣지 않는다. 스타일은 페이지 안에 짧게 둔다.

## 2. 검색 노출 막기

사용자는 앱을 조용히 쓰기를 원한다([배포 설계의 결정](Deployment.md#2-공개-범위)).

- 두 페이지 모두 `<meta name="robots" content="noindex, nofollow">`를 넣는다.
- 응답 헤더에도 `X-Robots-Tag: noindex, nofollow`를 붙인다. HTML을 읽지 않는 크롤러도 따르게 하기 위해서다.
- 개인 홈페이지 `qazcde.kr`에서는 두 페이지를 링크하지 않는다.

## 3. 내용

두 페이지는 한국어로 쓰고, 구글 심사를 위해 같은 내용을 영어로 아래에 붙인다.

### 3.1 앱 소개(`/about`)

- 앱 이름 Jjabtero와 한 줄 소개: 한 사람이 자기 논문 서재를 관리하는 개인용 참고문헌 관리 앱.
- 하는 일: 논문 검색(OpenAlex, arXiv)과 추가, 서재 목록·필터, 읽기 상태와 메모.
- 구글 계정을 쓰는 곳: 로그인(운영자 본인 계정만 허용)과 구글 드라이브 동기화(서재 파일을 사용자의 드라이브에 보관).
- 운영자 본인만 쓰는 앱이며 다른 사람의 가입을 받지 않는다는 것.
- 개인정보처리방침(`/privacy`) 링크.

### 3.2 개인정보처리방침(`/privacy`)

- 시행일.
- 받는 구글 사용자 데이터와 쓰는 곳:
  - 로그인(`openid email`): 이메일 주소. 허용한 계정인지 확인하는 데만 쓰고, 서명된 세션 쿠키에만 담는다.
  - 드라이브(`drive.file`): 앱이 만든 파일만 읽고 쓴다. 드라이브의 `Jjabtero/library.db` 하나에 서재를 보관한다. 다른 드라이브 파일에는 접근하지 않는다.
- 저장: 갱신 토큰은 서버의 비밀 설정에, 서재 작업 사본은 서버 디스크에 둔다. 서버 디스크는 재시작 때 지워진다.
- 공유하지 않음: 구글 사용자 데이터를 팔거나 넘기지 않고, 광고·분석·AI 모델 학습에 쓰지 않는다. 논문 검색어는 OpenAlex·arXiv에 보내지만 구글 사용자 데이터는 보내지 않는다.
- 구글 API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따른다는 문장과 그 정책 링크.
- 삭제: 구글 계정의 "서드 파티 앱 및 서비스"에서 접근 권한을 취소할 수 있고, 드라이브의 `Jjabtero` 폴더를 지우면 서재가 지워진다는 것.
- 연락처: GitHub 저장소의 이슈 페이지(`https://github.com/qazcdesnu/Jjabtero/issues`). 공개 페이지에 이메일을 적지 않기 위해 사용자가 골랐다.

## 4. 테스트

[test_public_pages](../../tests/test_public_pages.py)는 로그인을 켠 앱에서 다음을 확인한다.

- 두 페이지가 로그인 없이 200과 HTML을 돌려준다.
- 두 페이지에 `noindex` 메타 태그와 `X-Robots-Tag` 헤더가 있다.
- 소개 페이지가 개인정보처리방침을 링크한다.
- 개인정보처리방침이 드라이브 범위(`drive.file`), 제한적 사용 문장, 연락처를 담는다.
- 빌드된 화면이 있어도 두 경로는 정적 파일이 아니라 이 페이지를 돌려준다.
