# 서재 통계 설계

이 문서는 서재를 숫자와 차트로 보여 주는 "통계" 화면에서 보여 줄 항목, 필요한 데이터(읽은 시각, OpenAlex 세부 학문), API, 화면을 정한다. 서재 데이터 모델은 [서재 데이터 설계](Library.md#1-데이터-모델)에, 인용 캐시는 [인용 데이터 설계](Citations.md#4-저장)에, 차트 라이브러리는 [서재 인용 그래프 설계](CitationGraph.md#1-시각화-라이브러리)에 있다. 태스크는 [로드맵의 M5](../Roadmap.md#m5-서재-통계시각화)에 있다. 전체 문서 목록은 [문서 인덱스](../index.md)에서 확인한다.

## 1. 정한 것

사용자가 2026-11-18에 정했다.

- 지금 있는 데이터로 볼 수 있는 항목을 모두 넣고, 주제 분포를 더한다. 공동 저자 연결망은 나중에 한다.
- 주제는 두 가지로 본다. 사용자가 붙인 태그 분포와 OpenAlex의 학문(field)·세부 학문(subfield) 분포다. OpenAlex의 가장 잘게 나눈 단계인 주제(topic)는 가져오지 않는다.
  - 조사 결과(2026-11-18, 로컬 서재 17편과 인용 캐시 670편): 모든 논문에 주제가 있었다. 그러나 주제 단계는 서재 17편 가운데 4편이 어긋났고(AI-GAs와 범주론 논문이 "Psychiatry, Mental Health, Neuroscience", FLAN과 InstructGPT가 "Topic Modeling"), 틀린 것에 신뢰 점수 0.95가 붙은 경우도 있었다. 세부 학문은 거칠지만(11편이 "Artificial Intelligence") 틀린 것이 드물다.
- 앞으로는 논문을 "다 읽음"으로 바꾼 시각을 기록한다. 이미 다 읽은 논문은 시각을 모른다.
- 왼쪽 메뉴에 새 "통계" 화면을 둔다.
- 통계도 왼쪽에서 고른 태그(서재 필터의 태그)로 거른다. 그래프와 같은 방식이다([태그 설계](Tags.md#5-태그별-그래프)).
- 차트의 막대나 조각을 누르면 그 조건으로 거른 서재 목록을 연다.

## 2. 항목

| 항목 | 내용 | 차트 | 누르면 |
| --- | --- | --- | --- |
| 요약 | 논문 수, 읽기 상태별 수, PDF 있는 수, 하이라이트·메모가 있는 수, OpenAlex에 연결된 수 | 숫자 칸 | 읽기 상태 칸은 그 상태로 거르기 |
| 출판 연도 | 연도별 논문 수. 연도가 없는 논문은 "연도 없음" | 세로 막대 | 그 연도로 거르기 |
| 서재에 담은 시기 | `created_at`의 달별 논문 수 | 세로 막대 | 없음 |
| 다 읽은 시기 | `read_at`의 달별 논문 수. 시각을 모르는 다 읽은 논문 수를 따로 적는다 | 세로 막대 | 없음 |
| 항목 종류 | 종류별 논문 수 | 가로 막대 | 그 종류로 거르기 |
| 태그 | 태그별 논문 수, 많은 순 | 가로 막대 | 그 태그를 필터에 더하기 |
| OpenAlex 학문·세부 학문 | 세부 학문별 논문 수를 학문으로 묶어 보여 준다. 주제를 모르는 논문은 "주제 모름" | 가로 막대(학문별 색) | 그 세부 학문으로 거르기 |
| 저자 | 논문 수 많은 저자 상위 15명 | 가로 막대 | 그 저자 이름으로 글자 거르기 |
| 게재처 | 논문 수 많은 게재처 상위 15곳 | 가로 막대 | 그 게재처 이름으로 글자 거르기 |
| 서재 안에서 많이 인용된 논문 | 서재의 다른 논문에게 인용된 수 상위 10편([인용 그래프](CitationGraph.md#2-그래프-데이터)의 서재 안 인용 선) | 표 | 그 논문 상세 열기 |
| 전체 피인용이 많은 논문 | OpenAlex 피인용 수 상위 10편 | 표 | 그 논문 상세 열기 |

- 저자와 게재처 거르기는 지금 있는 글자 필터를 쓴다. 이름이 다른 논문의 제목에 들어 있으면 함께 나올 수 있지만, 새 필터 조건을 더하지 않기 위해서다.
- 세부 학문은 서재 필터에 새 조건 `subfields`를 더해 거른다. 서재 목록에는 세부 학문 열을 두지 않고, 상세에만 보여 준다.

## 3. 데이터

### 3.1 다 읽은 시각

- `papers`에 `read_at`(시각, 없어도 됨) 열을 더한다. 마이그레이션 0008이 더하며, 이미 있는 논문은 비어 있다.
- 읽기 상태를 다른 값에서 `read`로 바꿀 때 지금 시각을 넣는다. `read`에서 다른 값으로 바꾸면 비운다. `read`를 다시 `read`로 보내면 그대로 둔다([읽기 상태 저장 함수](ReadingStatus.md#2-저장-함수와-api)).
- 드라이브 자동 합치기는 `papers` 행을 통째로 고르므로(`updated_at`이 늦은 쪽) 따로 할 일이 없다([구글 드라이브 동기화 설계](DriveSync.md#10-자동-합치기)). 테스트로 확인한다.
- 논문 응답 `PaperOut`에 `read_at`을 더하고, 상세의 읽기 상태 아래에 "다 읽은 날"을 보여 준다.

### 3.2 OpenAlex 학문·세부 학문

- 서재 논문의 인용을 가져올 때 이미 부르는 OpenAlex 요청(논문 하나의 `referenced_works`)에 `primary_topic`을 함께 청한다. 새 요청이 늘지 않는다.
- 대표 주제(`primary_topic`)의 `field`와 `subfield`의 ID와 이름만 인용 캐시의 `fetches` 표에 둔다(`field_id`, `field`, `subfield_id`, `subfield`). 주제 단계 이름과 신뢰 점수는 버린다.
- 인용 캐시 버전(`CACHE_VERSION`)을 3으로 올린다. 그래서 다음 갱신 때 모든 서재 논문을 다시 가져와 세부 학문이 채워진다.
- 인용 캐시는 드라이브에도 올라가므로([인용 데이터 설계](Citations.md#4-저장)), 다른 컴퓨터도 받은 캐시에서 세부 학문을 읽는다.
- 서재 논문 응답 `PaperOut`에 `field`, `subfield`를 더해 상세와 세부 학문 거르기에 쓴다. OpenAlex에 연결되지 않았거나 아직 가져오지 않은 논문은 비어 있다.

## 4. API

- `GET /api/stats?tags=<이름>&tags=<이름>`가 2절의 모든 항목을 한 번에 돌려준다. 고른 태그를 모두 가진 서재 논문만 센다. 로그인이 켜져 있으면 로그인해야 쓴다.
- 응답은 항목마다 `[{"key": 값, "label": 표시 이름, "count": 수}, …]` 꼴의 목록이다. 많이 인용된 논문 두 표는 `[{"paper_id", "title", "count"}, …]`다.
- 새 모듈 `stats.py`에 둔다. 서재 데이터베이스와 인용 캐시를 읽기만 하므로 드라이브 올리기를 예약하지 않는다.

## 5. 화면

- 왼쪽 메뉴의 "그래프" 아래에 "통계"를 둔다. 그래프와 같이 넓은 화면(상세 칸 없음)이며, 처음 열 때 불러온다(`lazyView`).
- 차트는 인용 그래프와 같은 ECharts를 쓴다. 다크 모드 색을 따른다.
- 맨 위에 요약 숫자 칸, 그 아래에 차트를 두 줄씩 놓는다(좁은 화면에서는 한 줄씩).
- 도구 줄에 그래프 화면과 같은 태그 선택 칸을 둔다. 왼쪽 목록의 태그 선택과 같은 상태다.
- 차트를 누르면 서재 필터를 그 조건으로 바꾸고 서재 화면으로 간다(2절 "누르면" 칸). 태그 선택은 그대로 둔다.

## 7. 테스트

- 백엔드: `read_at` 넣기·비우기·그대로 두기, 마이그레이션 0008, 합치기에서 `read_at`이 따라가는지, `primary_topic`이 없거나 일부만 있는 응답, 캐시 버전 3에서 다시 가져오기, 통계 항목마다의 수(태그 거르기, 연도 없음, 주제 모름, 상위 개수 자르기).
- 프론트엔드: 세부 학문 필터, 통계 상태가 고른 태그로 통계를 청하는지, 차트 누르기가 만드는 필터.
- 브라우저: 로컬 서재와 시연 서재에서 통계 화면을 열고 누르기로 서재 목록이 걸러지는지 확인한다.
