# 제품 비전

이 문서는 Jjabtero가 무엇을, 누구를 위해, 어디까지 만드는지 정한다. 구현 방식은 [시스템 구조](Architecture.md)에, 할 일은 [로드맵](Roadmap.md)에 있다. 전체 문서 목록은 [문서 인덱스](index.md)에서 확인한다.

## 1. 목적

Jjabtero는 데이터사이언스 대학원생 한 명이 자신의 연구 방식에 맞춰 쓰는 개인 서지관리 앱이다. 지금 쓰는 Zotero를 대체하는 것이 목표다. Zotero가 주지 않는 기능을 넣는다. 논문 사이의 인용 관계를 바탕으로 연결하고 추천하는 기능, 그리고 서재를 분석하고 시각화하는 기능이다.

방향은 만들면서 구체화한다. 이 문서에는 지금까지 정한 것만 적고, 정하지 않은 것은 [5. 미결정 사항](#5-미결정-사항)에 남긴다. 기능을 만들 때마다 이 문서를 먼저 고친다.

## 2. 사용자

- 사용자는 개발자 본인 한 명이다. 데이터사이언스 대학원생이다.
- 여러 사용자, 계정, 공유, 협업 기능은 만들지 않는다.
- 사용자의 컴퓨터에서 로컬로 실행한다.

## 3. 핵심 요구사항

아래 기능은 사용자가 꼭 필요하다고 고른 것이다. 세부 동작은 기능마다 상세 설계 문서(`docs/design/`)에서 정한다.

| 기능 | 설명 |
| --- | --- |
| 논문 검색·필터 | 내 서재의 논문을 저자, 연도, 태그, 제목 등으로 찾고 걸러 본다. |
| 읽기 상태·메모 관리 | 논문마다 읽기 상태(예: 읽을 것, 읽는 중, 다 읽음)와 메모를 남긴다. |
| 인용 기반 연결·추천 | 논문 사이의 인용 관계로 거리를 재고, 가까운 논문을 연결하거나 추천한다. 임베딩 같은 의미 기반 방식은 쓰지 않는다. 인용 데이터는 OpenAlex에서 얻는다. 네 가지를 만든다([6. 인용 기반 연결·추천](#6-인용-기반-연결추천)). |
| 서재 통계·시각화 | 서재의 주제, 연도, 저자 분포 등을 분석하고 시각화한다. |
| 구글 드라이브 보관 | 서재를 사용자의 구글 드라이브 `Jjabtero` 폴더에 보관해, 다른 컴퓨터에서도 같은 서재를 쓴다. |

논문을 서재에 넣고 보관하는 기본 기능(논문 추가, 서지 정보 저장)은 위 기능들의 전제이므로 함께 만든다. 논문은 외부 논문 검색 사이트(OpenAlex, arXiv)에서 검색한 결과를 보고 골라 넣는다([논문 검색과 추가 설계](design/PaperSearch.md)). 논문마다 제목, 저자(순서 있는 목록), 연도, 게재처, DOI, URL, 항목 종류를 저장하고, 사용자가 붙이면 태그도 저장한다.

## 4. 범위

**포함**

- 위 핵심 요구사항.
- 브라우저에서 쓰는 로컬 웹 화면.
- 기본 기능을 쓸 수 있게 된 뒤 Render에 배포해, 내 컴퓨터가 아닌 곳에서도 브라우저로 쓴다([로드맵의 M2](Roadmap.md#m2-render-배포)). 배포해도 사용자는 본인 한 명이다. 주소는 `jjabtero.qazcde.kr`이고, 개인 홈페이지에는 소개하지 않는다([배포 설계](design/Deployment.md)).

**제외**

- 여러 사용자, 회원 가입. 로그인은 배포한 앱을 본인만 쓰게 하는 데만 쓰고, 구글 드라이브 로그인은 본인의 드라이브에 서재를 보관하는 데만 쓴다.
- 구글 드라이브 밖의 클라우드 저장소.
- 임베딩 등 의미 기반 추천.

## 5. 미결정 사항

아래 항목은 아직 정하지 않았다. 정하면 이 문서나 [시스템 구조](Architecture.md)에 반영하고 이 목록에서 지운다.

- 검색 말고 다른 추가 방법(직접 입력, DOI 입력, BibTeX 가져오기, PDF 등)을 더할지.
- 검색을 보조할 웹 검색을 쓸지, 쓴다면 어떤 검색 API를 쓸지.
- 기존 Zotero 서재를 가져올지, 가져온다면 어떻게 가져올지.
- PDF 파일을 저장하고 열람할지.
- 인용 거리 점수의 세부 계산식과, 피인용이 아주 많은 논문에서 인용 데이터를 어디까지 가져올지. M3의 설계에서 정한다.
- 통계·시각화에서 보여 줄 항목.
- 논문 인용 형식 내보내기(BibTeX 등)가 필요한지.

## 6. 인용 기반 연결·추천

사용자가 고른 네 가지 형태다. 인용 데이터는 OpenAlex에서 얻는다. 이미 검색에 쓰고 있고, 참고문헌과 피인용 목록을 모두 주며, 새 키나 계정이 필요 없기 때문이다. 만드는 순서와 태스크는 [로드맵의 M3](Roadmap.md#m3-인용-기반-연결추천)에 있다.

| 형태 | 설명 |
| --- | --- |
| 상세의 인용 목록 | 논문 상세에서 그 논문의 참고문헌과 그 논문을 인용한 논문을 보고, 서재에 있는지 표시하며, 없는 논문은 바로 추가한다. |
| 논문별 가까운 논문 | 논문 하나를 고르면, 참고문헌을 많이 공유하거나(서지 결합) 함께 많이 인용되는(공동 인용) 논문을 가까운 순서로 보여 준다. 서로 직접 인용하는 관계도 가깝게 본다. |
| 서재 밖 논문 추천 | 서재 논문들과 인용으로 많이 이어진 논문 가운데 아직 서재에 없는 것을 점수 순서로 보여 주고 바로 추가한다. |
| 서재 인용 그래프 | 서재 논문들이 서로 인용으로 어떻게 이어져 있는지 네트워크 그림으로 본다. |
